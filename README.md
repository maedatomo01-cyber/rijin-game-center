# 理不尽ゲームセンター

日本語の無料ブラウザーゲームをまとめた静的サイトです。

## 公開

GitHub Pages などの静的ホスティングで、リポジトリ直下の `index.html` を公開してください。`privacy.html` も同じ階層に配置します。ビルド作業やサーバー処理は必要ありません。

## 広告について

広告は未設定です。Google AdSense を利用する場合、サイトの所有確認、審査、発行者アカウントの承認後に、AdSense が提供するコードを `index.html` の `<head>` に追加し、広告ユニットを掲載してください。承認前に広告コードや `ads.txt` の内容を推測で作らないでください。
